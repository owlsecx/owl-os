# Contributing to Owl OS

Thank you for your interest in Owl OS and the OwlSec Toolkit.

## Responsible use

All tools in this project are intended **only** for authorised security testing, research, and defensive operations on systems you own or have explicit written permission to assess. Do not submit or discuss content that enables unauthorised access, crime, or harm.

## How to contribute

1. Open an issue describing the bug, doc fix, or improvement.
2. Keep pull requests focused and small (docs, metadata, packaging, or clear bug fixes).
3. Follow existing README style and attribution: **Khaled S. Haddad**, MIT License.
4. Do not commit secrets, credentials, or proprietary third-party binaries you are not allowed to redistribute.

## Reporting security issues

Email **support@owlsec.org** with details. Please allow reasonable time for a response before any public disclosure.

## Code of conduct

Be professional and respectful. Contributions that promote illegal activity or unsafe misuse will be rejected.
